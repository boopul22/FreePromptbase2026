# Publishing note: prompt pages (Sept 2026)

Applies to `prompt-schedule-tracklist.md` and `gallery-daily-ideas-2026-10.md`.

## The problem

The tracklist publishes exactly five prompts a day at 09:00, 12:00, 15:00, 18:00 and 21:00 IST, every day, from one batch. From the outside that looks like a content pipeline, not a person. Google's September 2026 spam update goes after scaled content, and a fixed machine cadence of near-identical templated pages is one of the easier patterns to spot. The October backlog is closer to reasonable (2 to 5 a day), but it is still 250 ideas queued in advance.

Nothing here changes pages that are already live. This is about what gets scheduled next.

## What to do from now on

1. **Vary the cadence.** Some days 1, some days 3, some days none. Don't fill every slot just because it is open. Stop using the five fixed times; pick times by hand, and not the same ones every day.
2. **Hand-review every prompt before it gets a date.** Open the page preview and check:
   - The prompt is actually different from the ones already on the site, not the same scene with the outfit or city swapped. If it is a near-copy, merge it into the existing page instead.
   - The intro, tips and FAQ say something specific to this prompt. Cut filler that could sit on any page.
   - The images match the prompt text and show fictional adults.
   - The title isn't a keyword variant of an existing title ("X prompt for boys", "X prompt for men", "X prompt Gemini").
3. **Schedule no more than a week ahead.** Long pre-filled queues are how the rigid pattern happened. Review, schedule a few days, then review again.
4. **Skip what doesn't pass.** An empty day is fine. A thin page is worse than no page.
5. **No copied or scraped content, no borrowed authorship.** Every prompt and every line of copy should be written for this site. Don't add "I tested this" style claims unless the testing actually happened.

## Before reusing the October backlog

Treat `gallery-daily-ideas-2026-10.md` as a list of ideas, not a schedule. Drop ideas that overlap with existing pages or with each other, and pick what goes live one short batch at a time using the checks above.
