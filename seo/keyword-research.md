the head term plateaus — publish/refresh `nano banana pro`, `nano banana 2`, and the
"how to use nano banana" FAQ now to catch the second wave before competition catches up.

## Strategy notes for future work
- **Database matters.** Prompt terms barely register in `us`; pull `in` for them.
- **Breakout terms** (no volume in tools yet) are *opportunities*, not dead ends —
  the tool hasn't caught up to the trend. The `tags.ts` set was built from rising-search
  research; keep adding rising variants early.
- **Difficulty ladder:** start ranking Cluster B + `free ai prompts` (KD 26–42),
  use that authority to push toward Cluster A head terms.
- **Seasonality:** refresh `holi prompt` before Feb; watch for new festival terms
  (Diwali, etc.) and new model launches (next "nano banana"-style breakout).
