This review covers that gap, the one redirect fix to do this week, a short repair list, and a first keyword focus for India.

Where the site stands

Free Prompt Base loads, uses HTTPS, sends www to the apex host, allows crawlers in robots.txt, and keeps a small set of keyword pages in the sitemap. Search Console is connected. India still accounts for most of the remaining clicks (21 of the last three months).

Google Search Console recorded a drop from about 100 impressions a day in early January 2026 to under 10 a day after 13 January, and it never came back. Over the last 16 months the pages with the most clicks were the homepage and hundreds of old /prompts/... URLs. Those old paths now 404. The new Gemini and Nano Banana pages almost do not appear in search.

If you only do one thing

Add a permanent 301 redirect (a “this page moved” signal for Google) so every old /prompts/... URL goes to a live page, instead of a 404.

A 404 tells Google the page is gone. That is what we fetched live: https://www.freepromptbase.com/prompts/chatgpt-prompt-for-answering-physics-problem-assignment-solutions 301s to the same path on the apex host, then that apex URL returns 404. About 774 of the first 1,000 Search Console page rows still mention /prompts/. Until those URLs point at something live, Google has nothing left to rank from the old library.

  1. Open Cloudflare, select freepromptbase.com, then go to Rules → Redirect Rules → Create rule.
  2. Name it Legacy /prompts/ URLs. Match when URI Path starts with /prompts/. Action: Dynamic redirect, status code 301, destination concat("https://freepromptbase.com", regex_replace(http.request.uri.path, "^/prompts", "")). That strips the old folder. If the new slug 404s, add a second rule below it: same match, destination https://freepromptbase.com/, status 301, so leftovers still land on the homepage.
  3. Check it worked: open https://freepromptbase.com/prompts/photo-prompts in a private window. You should land on a live page, not “doesn’t exist.” Then in Google Search Console open URL Inspection for that old address and click Request indexing. Repeat for the homepage and for https://freepromptbase.com/gemini-ai-photo-prompt-copy-paste.

Small fixes, in order

Old prompt folder returns 404 critical

Live fetch: /prompts/photo-prompts and the physics-assignment URL both return HTTP 404 after the www-to-apex 301. Search Console still lists those URLs from 2025.

Fix: The Cloudflare rule above. If you prefer code, add the same mapping next to the existing list in src/data/legacy-redirects.ts (that file already 301s a few old blog URLs, and we verified one of those hops works).

One live prompt page is empty

https://freepromptbase.com/bulldog-industrial-streetwear-fashion-prompt returns HTTP 200 with a 0-byte body, so it has no title, no heading, and no links. The sitemap still lists it. A 50-page crawl found this as the only empty title in the sample; 25 other prompt URLs loaded normally.

Fix: Unpublish or restore that prompt in the CMS so it either 404s cleanly or shows a full page. Then remove it from the sitemap if it stays unpublished.

New keyword pages are almost invisible

Last 16 months in Search Console: /gemini-ai-photo-prompt-copy-paste has 0 clicks and 1 impression. /nano-banana-prompt has 0 clicks and 2 impressions. Last three months, those pages have no query-level rows at all.
