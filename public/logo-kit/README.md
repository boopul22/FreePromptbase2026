# Logo kit

Logos generated from `logo.svg` (source of truth, 1080×1080, transparent).

| File | Size | Typical use |
|------|------|-------------|
| `logo.svg` | vector | Anywhere scalable |
| `favicon-16x16.png` | 16 | Browser tab |
| `favicon-32x32.png` | 32 | Browser tab / bookmarks |
| `favicon-48x48.png` | 48 | Windows / older browsers |
| `logo-64.png` | 64 | Small UI |
| `logo-96.png` | 96 | UI |
| `logo-128.png` | 128 | UI / store |
| `apple-touch-icon.png` | 180 | iOS home screen |
| `android-chrome-192x192.png` | 192 | PWA / Android |
| `logo-256.png` | 256 | General |
| `logo-384.png` | 384 | PWA splash |
| `android-chrome-512x512.png` | 512 | PWA / store |
| `logo-1024.png` | 1024 | App stores / hi-res |

All PNGs are square with a transparent background. Served at `/logo-kit/<file>`.
Regenerate with `sharp` from `logo.svg` if the brand mark changes.
